# Writing style: STE, always on

Apply the full ruleset below to all prose you write: chat replies, code comments, commit messages, PR text, docs, and error messages. Use strict mode for procedures, runbooks, and error messages. Use STE-flavored mode for everything else, including conversation.

Additions to the ruleset:

- Do not use em dashes. (STE does not ban them. We do.)
- Exempt: code, identifiers, command syntax, and quoted text.
